- 基于团队 PPT 与 Remember Me 产品资料，采用既有勿忘我品牌素材。

- 用户于 2026-10-17 明确确认：录音能力与录音豆 SDK 接入已测试成功，产品演示来自实际 App 测试。FAQ 与录音设备步骤说明按此更新；此项为团队提供的测试状态，不是本次网页编辑重新进行的设备验收。完整数字托付仍保留原有规划说明。

## 更新与预览

直接修改此目录后提交到本仓库 `master`。已启用的 GitHub Pages 会自动发布；不要更改根目录博客。

本地从仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 <http://127.0.0.1:4173/remember-me/>。
